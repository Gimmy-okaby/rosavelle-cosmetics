# ✨ لوير باريس كوزمتكس | Lueur Paris Cosmetics - متجر إلكتروني فاخر متكامل

متجر إلكتروني احترافي عالي الفخامة لمستحضرات التجميل والعناية بالبشرة، مبني بأحدث تقنيات الويب (React 19 + Vite + Tailwind CSS 4)، جاهز تماماً للتشغيل ولا ينقصه سوى ربط الدومين!

---

## 🌟 مميزات المتجر

### تجربة العميل (Customer Experience):
1. **تصميم باريسي فخم وعصري (Luxury Aesthetic)**:
   - ألوان نيود وهادية، تدرجات الذهب الوردي (Rose Gold)، وتأثيرات زجاجية (Glassmorphism).
   - واجهة متجاوبة 100% مع كافة أحجام الشاشات (الهواتف المحمولة، التابلت، والكمبيوتر).
   - دعم كامل للغة العربية (RTL) مع إمكانية التبديل للإنجليزية بضغطة زر.
   - تبديل العملات (جنيه مصري EGP، ريال سعودي SAR، دولار أمريكي USD).

2. **كتالوج منتجات واقعي ومتنوع**:
   - 12+ منتج عالي الدقة موزع على 4 أقسام رئيسية:
     - العناية بالبشرة (Skincare)
     - المكياج ومستحضرات التجميل (Makeup)
     - العناية بالشعر (Haircare)
     - العطور ومستحضرات الجسم (Fragrance & Body)
   - صور واقعية فائقة الجودة للمستحضرات.
   - محدد درجات ألوان المكياج (Shade Selector) مع دوائر ألوان تفاعلية.
   - محدد الأحجام والعبوات (30ml, 50ml, إلخ).
   - بطاقات تفاصيل كاملة: الفوائد، المكونات الفعالة، وطريقة الاستخدام.

3. **سلة مشتريات وقوائم أمنيات تفاعلية**:
   - درج سلة التسوق (Slide-over Cart Drawer) مع مؤشر تفاعلي لحساب المتبقي للشحن المجاني.
   - نظام كوبونات الخصم مع أكواد تجريبية جاهزة (`BEAUTY10`, `GLAM20`, `WELCOME`).
   - قائمة المفضلة (Wishlist) لحفظ المنتجات بنقرة واحدة.

4. **إتمام طلب مخصص للسوق المصري والعربي (Smart Localized Checkout)**:
   - اختيار المحافظات المصرية مع حساب تكلفة الشحن التلقائية (أو الشحن المجاني للطلبات الكبيرة).
   - 3 طرق دفع مدعومة:
     - **الدفع عند الاستلام (Cash on Delivery)**
     - **إنستاباي وفودافون كاش (InstaPay & E-Wallets)** مع أزرار نسخ سريعة لأرقام الحسابات
     - **بطاقات بنكية (Visa / MasterCard / Meeza)**
   - **زر تأكيد الطلب السريع عبر واتساب**: يفتح محادثة واتساب مع رسالة جاهزة منسقة تحتوي على رقم الطلب، بيانات العميل، الأصناف، والعنوان والمبلغ الإجمالي بضغطة زر!

5. **لوحة تحكم إدارية كاملة (Built-in Admin Dashboard)**:
   - متابعة الطلبات الواردة وتغيير حالتها (قيد المراجعة / تم الشحن / تم التسليم / ملغي).
   - إحصائيات المبيعات الفورية.
   - إضافة وحذف وتعديل المنتجات وأسعارها.
   - تعديل أرقام الواتساب وإنستاباي وفودافون كاش ونصوص العروض.

## 🛠️ التشغيل السريع محلياً

```bash
# تثبيت الحزم (إذا لزم الأمر)
npm install

# تشغيل خادم التطوير
npm run dev

# بناء النسخة النهائية للنشر على الدومين
npm run build
```

أو ببساطة اضغط مرتين على `run-dev.bat` أو `build.bat`.
